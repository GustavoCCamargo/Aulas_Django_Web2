## 🧠 Conceitos Abordados

O estudo do Django permite explorar diferentes conceitos fundamentais para o desenvolvimento de aplicações web, como:

- **Arquitetura MVT:** organização da aplicação em Model, View e Template.
- **Roteamento:** gerenciamento de URLs e direcionamento de requisições.
- **Models e ORM:** representação e manipulação de dados por meio de objetos Python.
- **Views:** processamento de requisições e definição das respostas.
- **Templates:** construção de páginas HTML com conteúdo dinâmico.
- **Formulários:** recebimento e validação de informações.
- **Migrações:** gerenciamento de alterações na estrutura do banco de dados.

> Os tópicos apresentados representam conceitos do framework Django e não necessariamente funcionalidades implementadas em todos os exercícios deste repositório.

## 🚀 Como Executar

### 1. Pré-requisitos

Para executar projetos desenvolvidos com Django, é necessário ter instalado:

- Python
- pip
- Git
- Django e demais dependências utilizadas pelo projeto

### 2. Clonar o repositório

```bash
git clone https://github.com/GustavoCCamargo/Aulas_Django_Web2.git
```

```bash
cd Aulas_Django_Web2
```

### 3. Criar um ambiente virtual

```bash
python -m venv venv
```

No Windows:

```bash
venv\Scripts\activate
```

No Linux/macOS:

```bash
source venv/bin/activate
```

### 4. Instalar as dependências

Caso o projeto possua um arquivo `requirements.txt`:

```bash
pip install -r requirements.txt
```

Caso contrário, para um projeto Django básico:

```bash
pip install django
```

### 5. Executar a aplicação

Acesse o diretório que contém o arquivo `manage.py` e execute:

```bash
python manage.py migrate
python manage.py runserver
```

O servidor de desenvolvimento normalmente estará disponível em:

`http://127.0.0.1:8000/`

> **Observação:** as instruções são gerais para projetos Django. Dependendo da organização dos exercícios, podem ser necessárias configurações adicionais.
